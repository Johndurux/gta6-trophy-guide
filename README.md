An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with a cited guide, a roadmap to the platinum, missable flags, filters and a spoiler setting, and a checklist whose progress is saved in the browser and exported to a file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
